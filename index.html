引擎能做什么

镜头推拉节奏

页面之间用 camera.z 做缩放推拉，配合 x/y 平移建立观看节奏。

动态拆解

部件从画面中心同时组装成爆炸图，退场时向外飞散。

数字滚动与图表生长

指标从 0 滚到目标值，条形图按比例生长，数据即主角。

跨页形变 morph

封面 logo 与结尾 logo 共享同一标记，飞入时形变而非淡入。

粒子与视差

环境层动效独立于内容时间轴，不会撑爆导出时长。

实时参数面板

放映时改配色、字体、速度、停留时长、播放方式，立即生效。

安装

clone 到 Claude Code 的 skills 目录即可被自动调用。

# macOS / Linux / Git Bash
git clone https://github.com/1481885917-lgtm/dynamic-keynote.git \
  ~/.claude/skills/dynamic-keynote

# Windows PowerShell
git clone https://github.com/1481885917-lgtm/dynamic-keynote.git $HOME\.claude\skills\dynamic-keynote

装好后 Claude Code 遇到「做发布会式演示 / pitch deck / 动效演示」时会自动调用，也可以直接说「用 dynamic-keynote 做一份演示」。
