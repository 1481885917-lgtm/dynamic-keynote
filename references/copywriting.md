# 文案规则 · Copywriting

演示文案的密度是传统 PPT 的 1/5。信息在观众脑子里，文字只负责点题。

---

## 1. 硬性规则

1. **一屏一个核心观点。** 说不清核心观点，就拆成两页。
2. **主标题 ≤ 12 个汉字 / 60 个英文字符。**
3. **副标题 ≤ 2 行，每行 ≤ 20 个汉字。**
4. **正文段落 ≤ 3 行。** 超过就拆要点或删。
5. **一页要点 ≤ 5 条。** 第 6 条开始没人看。
6. **数字必须有单位与对比基准**（"3.4×"，不是"3.4"；"对比上一代"）。
7. **动词开头。** "把整台设备，拆开给你看" ✅ / "我们把整台设备拆开…" ❌
8. **不用感叹号，不用"我们认为"，不用"赋能/抓手/闭环"这类黑话。**

## 2. 标题的三种写法

| 类型 | 模板 | 例 |
|---|---|---|
| 陈述 | 事实 + 结论 | "快，且持久" |
| 动作 | 动词 + 对象 | "把整台设备，拆开给你看" |
| 数字 | 一个有意义的数 | "18 小时，足够飞越一次时差" |

**反例**："XX 产品发布会" / "关于我们" / "产品优势介绍" —— 这是目录标题，不是标题。

## 3. 每屏的文案结构

```html
<div class="kicker">性能</div>        <!-- 类别，2–6 字 -->
<h2 class="h1">快，且持久</h2>         <!-- 观点，≤ 12 字 -->
<p class="lead">…</p>                  <!-- 展开，≤ 2 行，可选 -->
…                                    <!-- 图表 / 结构图 / 指标 -->
<p class="body">对比上一代 A18 Pro 实测基准</p>  <!-- 注释，可选 -->
```

眉标 → 观点 → 证据 → 注释。四层里可以只留两层。

## 4. 强调词的写法

强调词用 `.hl`（下划高亮）或 `.accent`，不要既加粗又变色又加下划 —— 一次只强调一个维度。

```html
<h2 class="h1">快，且<span class="accent">持久</span></h2>
<p class="lead">把整台设备，<span class="hl">拆开</span>给你看。</p>
```

强调词应落在**关键词**上（动词、数字、专有名词），不要落在虚词上。

## 5. 逐字显现的适用场景

`data-anim="typing"` 只用在**短标题**（≤ 12 字）。长句用 `rise` 或 `word-by-word`。

中文逐字显现的 stagger 建议 0.028–0.055；英文 0.02–0.04。超过 0.06 会显得拖沓。

## 6. 自检

- [ ] 把标题读出来，是不是一个完整的意思？
- [ ] 去掉所有形容词，信息量有没有下降？没有就说明形容词是废话。
- [ ] 每个数字都能回答"跟谁比"？
- [ ] 观众只看这一屏，能不能得出结论？
- [ ] 有没有出现"赋能 / 抓手 / 闭环 / 打法 / 颗粒度"？
- [ ] 首屏和末屏是否有呼应（同一个 logo / 同一个句式 / morph 形变）？
